# Frontend

## Purpose

The frontend will provide the user-facing application for the Smart Travel Expense Manager.

## Expected technology

A modern JavaScript or TypeScript frontend framework is expected. The specific framework has not yet been selected.

## Future responsibilities

The frontend is expected to provide the application interface and communicate with backend APIs once they are developed.

## Where code will be added

Frontend implementation will be added under this `frontend/` directory in a later development phase.

# Backend

The backend will provide server-side capabilities for the Smart Travel Expense Manager.

Python is the expected backend language. The framework and supporting technologies have not yet been selected.

## Future responsibilities

The backend is expected to handle API development, application services, integrations, and data access as those requirements are defined.

## Where code will be added

Backend implementation will be added under this `backend/` directory in a later development phase.
